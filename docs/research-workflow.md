# 一个可复用的交易研究记录流程

这份示例展示如何组织观察，不提供标的推荐、买卖点或收益判断。不同功能的开放范围请以当前产品界面为准。

## 1. 盘前：写下要观察的问题

- 选择自己需要研究的市场和标的，整理自选列表。
- 用日线或其他合适周期查看已有走势，标记关键区域。
- 记录一个可验证的问题，例如：“价格是否仍处在最近的整理区间内？”

## 2. 盘中：区分事实与解释

| 类型 | 记录示例 |
| --- | --- |
| 观察事实 | 当前周期的价格、成交量和图表结构发生了什么变化 |
| 自己的解释 | 这种变化可能意味着什么，还有哪些其他解释 |
| 待验证条件 | 后续需要看到什么，才会支持或推翻当前解释 |

需要持续观察时，可以根据自己使用的功能设置预警。预警提示的是条件变化，不能代替判断。

## 3. 盘后：留下可复核的记录

- 回看盘前提出的问题，记录哪些事实符合预期、哪些不符合。
- 在复盘工作台整理大盘、板块、个股及自己的交易记录。
- 写下下一次需要核对的数据和条件，不把复盘记录写成确定性预测。
