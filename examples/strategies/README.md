这三份脚本取自观潮在 2026-09-24 的公开系统内置策略，均为 Pine Script v5 的研究示例。GitHub 文件中的源码可以直接复制；配套 JSON 文件符合观潮脚本编辑器当前的导入格式。

| 策略 | 思路 | 复制源码 | 下载后导入 |
| --- | --- | --- | --- |
| 均线交叉 | EMA 9 上穿 EMA 21 入场，下穿离场 | [`.pine`](ema-crossover.pine) | [`.json`](ema-crossover.json) |
| MACD 信号交叉 | DIF 上穿 DEA 入场，下穿离场 | [`.pine`](macd-crossover.pine) | [`.json`](macd-crossover.json) |
| RSI 超买超卖 | RSI 上穿超卖线入场，下穿超买线离场 | [`.pine`](rsi-rebound.pine) | [`.json`](rsi-rebound.json) |

## 如何使用

1. [打开观潮](https://guanchaotv.com/app/)，登录后进入底部的「脚本编辑器」（也可按 `Ctrl+E`）。编辑器和策略回测目前需要专业版或更高会员；具体以产品当前显示的权益为准。
2. **直接导入**：打开表格中的 `.json` 文件，在 GitHub 文件页下载原文件；在脚本编辑器点「导入脚本」，选择该 JSON。导入只会载入编辑区，检查代码后按需另存为并运行或回测。
3. **复制粘贴**：打开 `.pine` 文件，复制全部源码；在脚本编辑器新建脚本并粘贴，检查参数后保存或运行。`.pine` 是纯源码，**不要**通过当前的「导入脚本」按钮导入；该按钮读取 JSON 格式。
4. 也可以在应用内的脚本广场直接查找同名内置策略。这里的文件方便下载、阅读和自行修改。

这些脚本仅展示信号逻辑。请自行核对市场交易规则、行情周期、费用、滑点与回测结果；编译成功不代表策略有效，也不构成投资建议或收益承诺。使用权限见[版权与使用说明](../../NOTICE.md)。
